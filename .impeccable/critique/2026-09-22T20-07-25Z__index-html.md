## Action Plan (P1 & P2 Fixes)

### Priority 1 (P1) - Usability & Accessibility
1. **CTA Focus Ring**: Change focus outline for `#btn-participar` and main buttons to high-contrast white/cyan ring (`outline: 3px solid #60a5fa; outline-offset: 2px`).
2. **Typography Scale**: Increase base mobile text size from 13px to 14px/16px to prevent iOS auto-zoom and improve outdoor readability.
3. **Mobile Layout Overflows**: Fix terms/nav overflow on 320px screens using flexible wrapping (`flex-wrap: wrap`) and compact padding.
4. **Form Feedback State**: Update form handling logic so feedback state correctly distinguishes validation errors vs success styling instead of hardcoded green success.
5. **Empty Ranking State**: Implement dedicated empty state card/UI when no rankings/participants exist.

### Priority 2 (P2) - Visual Boldness & Polish
1. **Hero Visual Enhancement**: Integrate `assets/moto-hero.svg` or enhance hero section with dynamic SVG graphic/badge for sovereign brand presentation.
2. **Polished Micro-Interactions**: Add subtle hover/active scales on card items and prize badges.
